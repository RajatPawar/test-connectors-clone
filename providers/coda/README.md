# Coda (Superhuman Docs) connector

Write + metadata connector on top of the existing proxy catalog entry (`providers/coda.go`).

## Auth and base URL

API key, sent as `Authorization: Bearer <token>`. Catalog `BaseURL` is `https://coda.io/apis`; every
endpoint lives under `/v1`, which the connector appends. The OpenAPI `servers` entry now says
`https://docs.superhuman.com/apis/v1` (the product was renamed), while the prose API reference and the
existing catalog entry use `https://coda.io/apis/v1`. The catalog entry was left unchanged.

## Write objects

| Object | Create | Update | RecordId |
|--------|--------|--------|----------|
| `docs` | `POST /v1/docs` (201, full Doc) | `PATCH /v1/docs/{docId}` (200, `{}`) | `id` from the create response; the input id on update |

Writable fields (from the spec request bodies): create takes `title`, `sourceDoc`, `timezone`,
`folderId`, `initialPage`; update takes `title`, `iconName`. Creating a doc requires the token owner
to be a Doc Maker in the workspace.

Coda applies document mutations asynchronously: the create response carries a `requestId` that can be
checked with `GET /v1/mutationStatus/{requestId}`. The connector does not poll; the doc id is returned
immediately and its content may take a few seconds to become visible through the API.

## Metadata

`docs` is described from `metadata/schemas.json`, generated by `scripts/openapi/schemagen` from
`metadata/schemagen.json`. `readOnly` reflects the create/update request bodies.

## Requested but not implemented

- **tables** and **table columns**: the API has no create/update endpoints for either — only
  `GET /docs/{docId}/tables[...]` and `GET /docs/{docId}/tables/{tableIdOrName}/columns[...]`.
- **table rows**: writes exist only at `POST /docs/{docId}/tables/{tableIdOrName}/rows` (array insert /
  upsert) and `PUT /docs/{docId}/tables/{tableIdOrName}/rows/{rowIdOrName}`. The doc and table ids are
  chosen per record and sit in the path, which the connector model cannot address. Use the proxy.
- Delete was explicitly out of scope.
